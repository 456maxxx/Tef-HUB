# Acervo visual complementar TFHub

Recursos organizados por finalidade para facilitar a extração e o reaproveitamento no front-end principal.

## Estrutura

- `turismo/`: paisagens fluviais, floresta, vivências e natureza amazônica
- `estabelecimentos/`: referências de restaurantes, cafés e hospedagem
- `gastronomia/`: pratos e cozinha regional brasileira
- `transporte/`: canoas, barcos e transporte fluvial
- `banners/`: cópias em formato apropriado para destaques promocionais
- `categorias/`: reservado para futuras ilustrações de categorias
- `icones/`: reservado para exportações de ícones

## Observação de uso

As fotografias são referências editoriais obtidas via Unsplash. Elas não devem ser apresentadas como registros
autênticos de estabelecimentos reais ou de locais específicos de Tefé sem validação prévia. Os componentes da
interface identificam o conteúdo comercial como ilustrativo.
